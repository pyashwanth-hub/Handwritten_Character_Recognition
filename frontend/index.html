Architectures

Deep Learning & ML Models

Comparative suite of deep convolutional networks, classic OCR benchmarks, and statistical pattern recognition algorithms.

Primary Model
🧬

CNN

Convolutional Neural Network

Multi-stage 2D convolutions with automated spatial feature hierarchy, max-pooling downsampling, and dense softmax classification.

Accuracy 99.43%
Params 214,884
Latency 4.2 ms
🏛️

LeNet-5

Handwritten Digit Recognition

The historic 1998 Yann LeCun architecture featuring 5x5 convolution kernels and subsampling layers engineered for digit verification.

Accuracy 97.16%
Params 60,456
Latency 3.1 ms
🔤

CRNN

Word & Sentence Recognition

Convolutional Recurrent Neural Network with connected component segmentation for full word transcription and sequential character decoding.

Accuracy 92.40%
Type Sequence
Latency 12.8 ms
🕸️

ANN

Artificial Neural Network

Fully-connected Multi-Layer Perceptron (MLP) with 256 and 128 hidden neurons utilizing ReLU activations on 784 flattened pixel vectors.

Accuracy 98.64%
Params 238,628
Latency 1.8 ms
📐

SVM

Support Vector Machine

Optimal margin hyperplanes in kernelized feature space using non-linear Radial Basis Function (RBF) kernels and Platt scaling probabilities.

Accuracy 98.98%
Kernel RBF
Latency 7.6 ms
👥

KNN

K-Nearest Neighbors

Non-parametric instance-based classification by distance-weighted voting over the 5 nearest neighbors in 784-dimensional Euclidean space.

Accuracy 97.73%
Neighbors K=5
Latency 5.4 ms

How It Works

From raw handwritten stroke pixels to high-confidence classified characters via a multi-stage deep learning pipeline.

1
✏️

Input Image

Handwritten drawing from digital canvas or photo upload from paper.

➔
2
⚙️

Preprocessing

Grayscale, inversion, noise reduction, and center-of-mass centering.

➔
3
🔍

Feature Extraction

Edge detection, stroke orientations, loops, and spatial gradients.

➔
4
🧬

CNN Model

Conv2D convolution filters, ReLU activations, and max-pooling compression.

➔
5
📊

Prediction

Dense layers with Softmax probability distribution over 36 classes.

➔
6
🎉

Final Output

Digitally decoded character, confidence score, and top candidate ranking.
